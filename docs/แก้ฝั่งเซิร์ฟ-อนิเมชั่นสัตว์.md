# รายการแก้ฝั่งเซิร์ฟ — อนิเมชั่นสัตว์ / ดาเมจไม่ตรงจอ

เอกสารนี้เขียนไว้ให้อีก agent รับงานต่อ **อ่านจบก่อนแตะโค้ด**  
ฝั่ง client แพตช์ส่วนที่เกี่ยวกับเรื่องนี้ไปแล้ว (log ตอนโหลด prefab ไม่ได้ · แก้ fade · REVERSE) — **งานที่เหลือเกือบทั้งหมดอยู่ฝั่งเซิร์ฟ**

กฎเหล็ก: ห้ามแก้ `server/GameCode/**` · ใช้ภาษาไทย · ก่อนเดาให้อิงต้นฉบับ/ข้อมูลจริง · เสร็จระบบหนึ่งหยุดรอคำสั่ง

วันที่เขียน: 7 ก.ย. 2026

---

## อาการที่ผู้เล่นเห็น

สัตว์ยืนนิ่ง (หรือยืนท่า BattleStand) แต่ผู้เล่นโดนดาเมจเข้ามาจริง — ไม่มีท่าเหวี่ยง/พุ่งให้เห็นบนจอ  
ถ้าปล่อยนาน ๆ สัตว์ทั้งเกาะจะค่อย ๆ ยืนนิ่งหมด เพราะ aggro ไม่เคยถูกเคลียร์

---

## สาเหตุ (ห่วงโซ่หลักฐาน)

ดาเมจกับอนิเมชั่นเดิน**คนละสาย**:

1. เซิร์ฟกัดผ่าน `Damaged` ใน `server/Core/Player.Hunting.cs` → `AnimalTurn` (~118-172)  
   ส่ง `Effects = DamageEffects.None` · **ไม่ส่ง `Move` ท่าโจมตี** · **ไม่ส่ง `CombatInteraction`**
2. อนิเมชั่นสัตว์ป่าฝั่ง client ถูกขับด้วย `Move.MotionName` อย่างเดียว  
   (`client/AnimalManager.HandleMoveMsg` → `AnimalBehavior.PlayAnimationMovement` → `Anim.CrossFade`)  
   `AnimalBehavior.Update()` **ไม่มีตรรกะเลือกท่าเอง** — เซิร์ฟไม่ส่งท่าใหม่ สัตว์แช่ท่าเดิมตลอด
3. เซิร์ฟไม่มีข้อมูลชื่อ clip โจมตีจะส่ง:  
   `server/Support/AnimalMotions.cs` คลาส `Motions` มีแค่ Stand/Idle/Move/Eat/Alert/Dead/BattleStand/Groggy/Blow  
   **ไม่มีฟิลด์ attack** และโหลดจาก JSON เฉพาะ 9 คีย์นี้  
   ไฟล์ `server/data/assets/derived/animal_motions.json` ที่ดัมป์ไว้มี `attack_normal` = **0 รายการ** ทั้งไฟล์  
   ทั้งที่ client รองรับครบ: `client/AnimalFrameworkResource.cs`  
   `_attackMotionKeys = { "attack_normal", "attack_strong", "attack_dash", "counter" }`  
   และ `client/BotBridge.cs` (~721-726) สั่งดัมป์คีย์ attack ไว้แล้ว ⇒ ไฟล์บนดิสก์ล้าสมัย (ดัมป์ก่อนมีคีย์ attack) หรือตอนดัมป์ element ว่าง
4. เครื่องจักรต้นฉบับที่ client รองรับแล้วแต่เซิร์ฟไม่เคยยิง:  
   `client/ObjectManager.cs` รับ `CombatInteraction`  
   - `Details["status"]` → `AnimalBehavior.Status`  
   - `Details["notice_attack"]` → `AnimalBehavior.AttackNotice` (วงแหวนเตือนล่วงหน้า ~2 วิ ก่อนฟาด)  
   - `Details["look_at"]` + `TargetId` → หันหัวมองเป้า  
   struct มีอยู่แล้วที่ `server/GameCode/Messages/CombatInteraction.cs` — **ห้ามแก้ไฟล์นั้น** แค่ `new CombatInteraction { ... }` ใน `server/Core`

ปัจจัยเสริม: `animal.Tile` ถูกเซ็ตเป็นจุดหมายทันทีตอนเริ่มเดินเล่น (`AnimalManager.BuildWander`) ขณะที่บนจอสัตว์ยังไต่ path ⇒ ระยะกัดบนเซิร์ฟ (4 ช่องจาก tile) อาจไม่ตรงตำแหน่งที่ผู้เล่นเห็น

## งานที่ต้องทำ (เรียงลำดับ)

### 1) ดัมป์ชื่อ clip โจมตีใหม่ แล้วขยาย `AnimalMotions`  ← ทำก่อน

1. เปิดเกม+เซิร์ฟท้องถิ่น แล้วรัน `animdump` ผ่าน BotBridge ชุดปัจจุบัน  
   (คีย์ attack มีใน `client/BotBridge.cs` แล้ว — ดูคำสั่งในคอมเมนต์/`bot.ps1`)  
   เป้าหมาย: เขียนทับ `server/data/assets/derived/animal_motions.json` ให้มี  
   `attack_normal` / `attack_strong` (และถ้ามี `attack_dash` / `counter`)  
2. ขยาย `server/Support/AnimalMotions.cs`:
   - เพิ่มฟิลด์ใน `Motions` เช่น `AttackNormal`, `AttackStrong` (ชื่อภาษาไทยในคอมเมนต์ได้)
   - อ่านจาก JSON: `o["attack_normal"]`, `o["attack_strong"]`
   - เพิ่มเมธอดช่วย เช่น `AttackOf(ushort entityType)` ที่คืน `AttackNormal ?? AttackStrong`  
3. ตรวจหลังโหลด: log ว่ามีกี่ชนิดที่มีท่าโจมตี (อย่าเงียบถ้าได้ 0)

### 2) ใน `AnimalTurn` — ส่งท่าโจมตีก่อน `Damaged`

ไฟล์: `server/Core/Player.Hunting.cs` (~118-172)

ก่อน `_world.BroadCast(new Damaged { ... })`:

1. ถ้ามีชื่อ clip โจมตี → broadcast `Move`/`ToMotionMessage` แบบ one-shot  
   (`MotionOption.NORMAL` ไม่ใช่ LOOPING) ด้วยชื่อ clip นั้น  
   แล้วค่อยส่งท่ายืน/BattleStand กลับหลังจบคลิป (หรือพึ่ง client crossfade เมื่อส่ง Move ถัดไป)
2. (แนะนำพร้อมกัน) ส่ง `CombatInteraction`:
   ```
   EntityId = animal.EntityId
   TargetId = ผู้เล่น
   Details["notice_attack"] = <unix มิลลิวินาทีของจังหวะฟาด>
   Details["status"] = (int)AnimalStatus.Battle   // = 12
   Details["look_at"] = 1
   ```
   ค่าสถานะจาก `client/Shared.Animal/AnimalStatus.cs` (และมีฝั่งเซิร์ฟใน GameCode ชุดเดียวกัน):  
   `Battle = 12` · `Peace = 19` · `Invalid = -1`  
   ฝั่ง client แปลงด้วย `(AnimalStatus)msg.Details["status"]` และข้ามถ้า TargetId ไม่ใช่ผู้เล่นท้องถิ่น (`ObjectManager.cs:125`)
   **หน่วยสำคัญ:** ฝั่ง client หาร `notice_attack` ด้วย 1000 เอง (`ObjectManager.cs:138`) ⇒ ต้องส่งเป็น**มิลลิวินาที**  
   และ client เผื่อวงแหวนมาแล้ว ~2 วินาที (`AnimalBehavior.AttackNotice`) — ตั้งเวลาฟาดให้สอดคล้อง
3. (ถ้าทำได้) ส่ง `Move` เดินเข้าหาเป้าเมื่อผู้เล่นอยู่นอกระยะกัดจริง แทนการกัดจากระยะ 4 ช่องโดยไม่ขยับ

อย่าแตะ `server/GameCode/**` — สร้างข้อความใน `server/Core` ได้เลย

### 3) เคลียร์ aggro เมื่อผู้เล่นหนีไกล  ← สำคัญ ไม่ใช่ของแถม

ตอนนี้ `AggroTargetId` ถูกตั้งแล้ว**ไม่มีจุดไหนเคลียร์เป็นค่าว่าง** (grep ทั้งเซิร์ฟ)  
`AnimalManager.Process` ข้ามการเดินเล่นตลอดถ้ายังมี aggro ⇒ สัตว์ค้าง BattleStand ตลอดชีพ

แก้ใน `AnimalTurn` / `SyncAnimalVisibility`:

- ถ้า `hunting` แต่ `!IsWithinTiles(...)` เกิน N วินาที (กำหนดเอง แล้วเขียนคอมเมนต์ `**ค่าของเรา**`)  
  → เคลียร์ `AggroTargetId`  
  → broadcast ท่ายืนปกติ  
  → ส่ง `CombatInteraction` status = สันติ (ถ้าทำข้อ 2 แล้ว)

### 4) ใส่ `DamageEffects` ตอนสัตว์กัด

ตอนนี้ `Effects = DamageEffects.None` เสมอ (`Player.Hunting.cs:155`)  
client (`DamagedProcesser`) จะเล่นท่าเจ็บ/กระเด็นเฉพาะเมื่อ flag เปิด

แก้: ตั้ง `KnockBack` หรือ `Blow` ตาม `info.SizeLevel` (มีตัวช่วย `BodyAttackTypeOf` อยู่แล้วแถว ๆ 198)  
อย่าลืมว่า `AttackType` ใช้ SmallBody/LargeBody อยู่แล้ว — แยกจาก Effects

### 5) (ถ้ายังว่าง) ส่ง `look_at` / status ตอนเข้า-พ้นโหมดสู้

ทำให้ไอคอนสถานะบนหัวสัตว์ (`AnimalFloatingGroup`) และ head tracking ถูกต้อง

## สิ่งที่**ไม่ต้อง**ทำฝั่งเซิร์ฟ

- ห้ามแก้ `server/GameCode/**`
- ไม่ต้องแก้ client เพิ่มเพื่อให้ท่าโจมตีเล่น — พอเซิร์ฟส่ง `Move` ชื่อ clip ถูก ฝั่งเกมเล่นเอง พร้อม AnimationEvent เสียง/FX
- `BotBridge` ใช้แค่ทดสอบ อย่าพึ่งมันในโค้ดเซิร์ฟจริง

---

## วิธีเทสหลังแก้

1. `dotnet build server -c Release` (ปิดเซิร์ฟก่อน)
2. เปิดเซิร์ฟ+เกม · เดินเข้าใกล้วัว/หมาป่า/ไดโนเสาร์กินเนื้อ
3. ต้องเห็น: วงแหวนเตือน (ถ้าส่ง notice_attack) → ท่าโจมตี → เลือดลด → ตัวละครมีท่าเจ็บ
4. หนีห่างเกินระยะที่ตั้งไว้ → สัตว์กลับท่ายืน/เดินเล่น ไม่วิ่งตามทั้งเกาะแบบแช่ BattleStand
5. เช็ค log เซิร์ฟว่าโหลดท่าโจมตีได้ > 0 ชนิด · เช็ค log เกมว่าไม่มี NRE ชุดใหม่
