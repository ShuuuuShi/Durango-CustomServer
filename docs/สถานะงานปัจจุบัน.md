## 5. กับดักที่เสียเวลาไปแล้ว — อย่าเหยียบซ้ำ

1. **`default(Abort)` / `default(Error)` ทำเกมแครช**
   `PackString(null)` ไม่โยน แต่เขียน nil (`0xc0`) → ฝั่งเกม `UnpackGettextFromMsgPack` คืน null
   → `LimitText(null).Length` → NRE (`client/GameManager.cs:292`) ⇒ ต้องมี `Text` เสมอ
2. **`Connection.Recv` ตัวหลังทับตัวหน้า** สำหรับ TypeCode เดียวกัน (`RegisterMessageHandlerToRegistry` ลบก่อนแล้วค่อยเพิ่ม)
   ⇒ ลงทะเบียนซ้ำ = handler เดิมหายเงียบ
3. **`ReplySequenceMark` (TypeCode 0)** — ฝั่งเกมลบ handler ของ seq ทิ้งหลังได้คำตอบแรก
   จะตอบหลายข้อความบน seq เดียวต้องครอบหัว/ท้ายด้วย `Send(default(ReplySequenceMark), seq)`
4. **`Floor` ของสิ่งปลูกสร้าง**: `null` = กลางแจ้ง · `0` = **ในบ้าน** ⇒ ห้ามรวมด้วย `?? 0` (พังการวางเฟอร์นิเจอร์ในบ้านทั้งระบบ)
5. **`Item.Ext` เป็น `object`** — ผ่าน JSON แล้วกลายเป็น `JObject` แล้ว `Item.Pack` ไม่มี `else`
   ⇒ ไม่เขียนอะไรเลยสักไบต์ ฟิลด์ที่เหลือเลื่อนหมด · ซ่อมด้วย `ItemExtRepair.Rebuild`
6. **ชื่อไอเทมมาจากเซิร์ฟ ไม่ใช่ catalog ของเกม** (`client/Durango.Logic.Item/ItemData.cs:132`)
   ⇒ ภาษาไทยต้องแปลฝั่งเซิร์ฟผ่าน `.mo` (`server/Support/MoCatalog.cs` โหลด 33,440 รายการก่อน `DataStore.Load`)
7. **PowerShell 5.1 อ่านไฟล์ที่ไม่มี BOM เป็น ANSI** ⇒ สคริปต์ที่มีภาษาไทยต้องเซฟเป็น UTF-8 **พร้อม BOM**
8. **`sed` ที่ใส่ `\n` จะได้ `\n` ตัวอักษรจริง** ไม่ใช่ขึ้นบรรทัดใหม่ ⇒ ใช้ heredoc เขียนทั้งไฟล์แทน
9. **heredoc ยาว ๆ ผ่าน Bash ล้มด้วย `ENAMETOOLONG: uv_spawn`** ⇒ เขียนสคริปต์ python ด้วย Write tool แล้วค่อยรัน
10. **Python บน Windows อ่าน path แบบ `/c/Users/...` ไม่ได้** ⇒ ใช้ `C:\Users\...`
11. **`tools/pack-vps.ps1` เคยแอบใส่ `account.key` ของเครื่องคนแพ็กลงชุดแจก** — ใครโหลดไปจะเข้าตัวละครเดียวกันหมด
    ตอนนี้ใส่ใน `/XF` แล้ว **อย่าเอาออก** (ตอนนี้ `game/account.key` โผล่มาอีก ต้องเช็คก่อนแพ็ก)
12. **เคยทำระบบแพตช์พังตอน deploy** — release ใหม่กลายเป็น Latest โดยไม่มี `manifest.json`
    ทำให้ `releases/latest/download/manifest.json` 404 แล้วเครื่องผู้เล่นทุกเครื่องอัปเดตไม่ได้
13. **เคยทำงานผิด branch** (`OpenCode` แทน `main`) แล้วงานที่แก้ไป "หายไป" — เช็ค `git branch --show-current` ก่อนเสมอ
