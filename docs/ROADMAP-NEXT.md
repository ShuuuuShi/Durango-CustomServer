## หลักการ

1. **โปรโตคอลไม่ใช่คอขวดหลักแล้ว** — `GameCode/Messages` ครบ · handler เกือบครอบคลุมข้อความที่เกมยิง
2. **blocker เปิดเบต้าวงปิด (บัญชี/เจ้าของ/โกง/รับคน/แอดมิน) ปิดในเอกสารแล้ว** — เหลือพิสูจน์บน VPS
3. **อย่าขยายแบบ Nexon (กระจายโหนด) จนกว่าเซิร์ฟเดี่ยวนิ่งและมีผู้เล่นจริง**
4. งานใหม่ทุกชิ้นต้องมี: handler + ข้อมูลใน `data/assets` + เทสในเกมจริง (ไม่นับแค่ compile)

## เฟส N0 — Ship LastHuman ขึ้นไลฟ์ทดสอบ (1–2 สัปดาห์)

**เป้าหมาย:** VPS รัน LastHuman ไม่ใช่ Opencode · คนวงปิดเล่นได้

| งาน | สำเร็จเมื่อ |
|---|---|
| Deploy LastHuman Release ขึ้น VPS | gateway/game ขึ้น · ภาษาไทยโหลด · `/admin` ใช้ได้ |
| เทส assetbundle ดาวน์โหลด | มือถือ/PC นอกเครื่อง dev เข้าโลกได้โดยไม่ค้าง TPS |
| Backup + logrotate ทำงานบน VPS | มี snapshot ย้อนได้ |
| Commit/แท็กเวอร์ชัน | มี tag เช่น `v0.2.0-lasthuman-vps` |

**ทางออก:** เบต้าวงปิด (เพื่อนที่ไว้ใจ) ได้

## เฟส N1 — คุณภาพการต่อสู้/สัตว์ (ขนานกับ N0 ได้)

**เป้าหมาย:** ล่าสัตว์รู้สึกถูกต้อง · ไม่มีดาเมจผีจากตัวนิ่ง

| งาน | สำเร็จเมื่อ |
|---|---|
| ส่งอนิเมะ/Move ตอนสัตว์โจมตี | ตาม `แก้ฝั่งเซิร์ฟ-อนิเมชั่นสัตว์.md` ยืนยันในเกม |
| กรง + บังเหียน + อาหารสัตว์ | หน้าต่างเลือกสัตว์ไม่ว่าง · เลี้ยง/อายุหน่วยถูก |
| เทสทามิงครบวงจรบน VPS | จับ → กรง → เชื่อง → เรียกออก → ขี่/งาน |

## เฟส N2 — ทำให้ระบบที่มี handler แล้ว “มีเนื้อ”

**เป้าหมาย:** UI ไม่ได้โครงว่างหลอกตา

| ระบบ | สำเร็จเมื่อ |
|---|---|
| ตลาดผู้เล่น | ลงขาย/ซื้อ แล้วของและเงินเปลี่ยนจริง · เซฟได้ |
| หลุมอุกกาบาต/รอยแยก | ลงทุนเปิดได้ตาม `CrackTuning` |
| Radiotower / แจ้งเตือนแคลน | ช่องทางจริง หรือปิดฟีเจอร์ใน UI ชัดเจน |
| ค่าแคลน/ที่ดินที่ควร persist | ไม่หายตอนล็อกเอาต์ |
| เทสสุ่มยิง message จาก log `[conn] ไม่มี handler` | เหลือ 0 ของเส้นทางผู้เล่นจริง |

## เฟส N3 — เสถียรภาพมัลติเพลเยอร์ + ความปลอดภัยสาธารณะ

**เป้าหมาย:** พร้อมเปิดกว้างกว่าวงปิด

| งาน | สำเร็จเมื่อ |
|---|---|
| Login จริง + HTTPS (หรืออย่างน้อย TLS ที่ gateway) | ไม่ดัก `account.key` กลางทางได้ง่าย |
| เลข build แยกจาก `5.2.1` + บังคับเวอร์ชัน | เกมเก่าเข้าไม่ได้ |
| เพดาน/คิวเมื่อคนล้น | ไม่ล่มตอนบุก |
| harden วาร์ป/Dash/Depart | ไม่วาร์ปตอนตาย · ไม่สแปม |
| เฝ้าระวัง (health alert) | รู้เมื่อเซิร์ฟล่มโดยไม่ต้องมีคนบอก |

## เฟส N4 — เอนด์เกม / เนื้อหาลึก (เลือกทำ)

เรียงตามคุณค่าเบต้า ไม่ใช่ตามความยาก Nexon:

1. สมดุลเกาะหลายใบ + ประชากร (ถ้าคนเยอะ)
2. แคลนวอร์ / ยึดจุดสำคัญ (ถ้าต้องการ PvP องค์กร)
3. PvP เกาะเฉพาะ / Lawless
4. เศรษฐกิจตลาดสมบูรณ์ + ป้องกันปั่นราคา
5. สูตรดาเมจ/เลือดสัตว์จากข้อมูลเกมเต็ม

---

## เฟส N5 — สถาปัตยกรรมแบบ Nexon (ทำเมื่อมีเหตุผลสเกล)

ทำเมื่อ: ผู้เล่นพร้อมกันมากจนเซิร์ฟเดี่ยวไม่ไหว หรือต้องการโลกถาวรขนาดใหญ่จริง

- แยก Zoo / Garden / Colosseum / Frontend
- เอกสารดินต่อ chunk + ธุรกรรม
- mirage LOD
- DB กระจาย (Couchbase หรือเทียบเท่า)
- ดูรายละเอียดใน `NEXON-SERVER-ARCHITECTURE.md`

**อย่าเริ่มเฟสนี้เพื่อ “ให้เหมือน Nexon” โดยยังไม่ผ่าน N0–N3**

## เทียบกับเอกสารระบบที่คุยไว้

| ระบบในเอกสาร | สถานะใน LastHuman | งานเหลือหลัก |
|---|---|---|
| โปรโตคอล | แข็งแรงมาก | อัป scan · เทสของจริง |

| Gathering | มี + เซฟ harvest | garden vs ของที่เกมวาดเอง — อย่าบล็อกผิด |
| Craft / Build | มี | บั๊ก UI ฝั่งเกมบางจุด |
| Animals / Combat / Tame | มี | อนิเมะโจมตี · กรง |
| Skills / Jobs | มี | เทสวิจัยหมวด |
| Estate / Clan / Party / Mail | handler มี | ของจริง + radiotower |
| Travel / หลายเกาะ | มี | สมดุลประชากรเมื่อสเกลขึ้น |
| Market | stub เศรษฐกิจ | N2 |
| Nexon distributed | ไม่มี (ถูกต้องสำหรับตอนนี้) | N5 เท่านั้น |

## คำตอบสั้น: ต้องทำอะไรเพิ่ม?

ไม่ต้องไปหาโปรโตคอลใหม่เป็นหลักแล้ว  
**ต้องทำให้ของที่มี “ขึ้นไลฟ์ + ถูกในเกม + ปลอดภัยพอเปิดคน”** ตาม N0→N3  
แล้วค่อยเลือกเอนด์เกม (N4) หรือสเกล Nexon (N5)
