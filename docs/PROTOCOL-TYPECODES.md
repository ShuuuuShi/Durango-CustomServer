## คำเตือน

- ตัวเลขเหล่านี้ต้องตรงกับ client เดิม — **ห้ามเปลี่ยน TypeCode / ห้ามลบ message / ห้ามสลับเลข**

- coverage แยกอยู่ที่ `docs/protocol-coverage.md` — ไฟล์นี้เป็น**แคตตาล็อกเลขล้วน**
